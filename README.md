##  Selected Projects

###  Bookstore Support V2

A retrieval-based customer support automation built with n8n, Gemini Embeddings, Supabase, PostgreSQL, and pgvector.

The system transforms customer messages into embeddings, performs semantic search against an approved knowledge base, applies a similarity threshold, returns stored answers when a reliable match is found, and logs the interaction.

**Focus:** Automation · APIs · Embeddings · Vector Search · PostgreSQL · Debugging

---

###  Event Services Lead Qualification & CRM Automation

An end-to-end GoHighLevel CRM automation for managing event inquiries from initial submission to consultation booking.

It includes lead capture, rule-based qualification, opportunity management, automated follow-up tasks, internal notifications, one-time booking links, appointment booking, and automatic pipeline updates.

**Focus:** CRM Architecture · Workflow Automation · Business Logic · Testing · Appointment Automation
